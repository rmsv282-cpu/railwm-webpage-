Requirements

Install these before compiling:

  • libx11-dev
  • pkg-config
  • meson
  • ninja
  • libxcursor-dev
  • libdbus-1-dev
  • libcairo-dev
  • xorg
  • cmake

Compile

meson setup build
ninja -C build

Install

Copy the binaries into /usr/local/bin, or into ~/.local/bin if it is on your PATH.

Release binary

Unpack the release, then follow the install step above.

tar -xvf railwm-bin.tar.xz
